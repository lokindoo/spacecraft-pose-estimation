# Sim2Science 2026 camera-ready: source and number ledger

The LaTeX source of the workshop paper as submitted on 30 Oct 2026, with the
compiled [article.pdf](article.pdf), and the script that checks every number in
it against [`results/`](../../results/).

## Check the numbers

```bash
python check_numbers.py            # from this directory
python check_numbers.py --verbose  # also list the claims that pass
```

Each claim names the exact phrase it checks and the formula that should
produce its numbers from the results CSVs. A claim fails if a number is off by
more than its stated precision allows, or if the phrase is no longer in the
text. On this source: 56 claims plus structural checks, 0 failures.

## Rebuild

```bash
python make_revision_appendix.py   # regenerates appendix_revision.tex (App. D) from results/revision/
pdflatex article && pdflatex article
```

`article.bbl` is included, so BibTeX is not needed. Only the two figures the
paper uses are here; `scripts/make_figures.py` regenerates them (see the main
README).

## What differs from the submitted folder

- **`check_numbers.py` and `make_revision_appendix.py`:** only the line that
  locates `results/` changed, to fit this repository's layout.
- **`appendix.tex`:** its header says it is generated by `make_appendix.py`.
  That was true before the revision. Since then it has been edited by hand, so
  the generator is not included; the file itself is as submitted.
